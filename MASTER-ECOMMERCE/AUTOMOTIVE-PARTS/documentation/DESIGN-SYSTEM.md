# Design system
Direction: premium dark automotive, restraint, precise type, generous space (apple-design idea; ui-ux-pro-max searches consulted: its "luxury dark" result suggested gold accent + serif; rejected the serif/glass effects as too fashion/SaaS, kept dark neutral + single warm accent).
- **Colour tokens** (`frontend/public/css/app.css` `:root`): graphite `--bg-0 #0b0c0e`, `--bg-1 #111316`, `--bg-2 #16181c`, `--bg-3 #1d2025`, lines `#272b32/#383e47`; text off-white `#ece9e2`, silver `#b4bac3`, muted `#8d95a0`; **one accent: amber `#e3a53a`** (hover `#f0bb5c`, ink `#171002`). Danger/ok used only for status. Dev warnings use orange banner.
- **Type**: Inter Tight (UI/display) + JetBrains Mono (OEM numbers, eyebrows, tags) via Google Fonts `display=swap`, system fallback stack. Fluid sizes with `clamp()`.
- **Spacing**: 8pt scale `--sp-1..12` (8-96px). 12-col grid `.grid/.col-*`, container max 1280px, gutter `clamp(16px,4vw,32px)`.
- **Components**: buttons (primary amber, default, ghost, sm), inputs (48px min height, visible focus ring 2px amber), product card (neutral light tile, `object-fit:contain`, never stretched; images render at natural size (never upscaled), caption "Photo from supplier catalogue"), mega-menu, drawers (cart/menu with focus trap + Esc), bottom nav + sticky ATC on mobile, notices, tags, tables, accordions.
- **Hero**: CSS/SVG abstract headlight glow and light beams (no photography available offline). **Real hero photography must be supplied by the business** (Shopify theme section has an image picker).
- **Accessibility**: skip link, labels on every field, focus rings, `prefers-reduced-motion`, 44px+ touch targets, contrast: text on `#0b0c0e` >= 7:1 for body, muted >= 5.5:1; amber on dark >= 8:1. Checked structurally by the e2e script (labels, h1, alt, duplicate ids); not audited with a screen reader or axe.
- **Performance**: lazy images with width/height, gzip, immutable caching for product images, ~24KB CSS, ~6KB JS, no framework.
